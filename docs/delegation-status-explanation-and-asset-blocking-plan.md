# خطة: شرح الإتمام في «حالة الإنابة» + حجب الأموال ذات الإنابة السارية

> حالة الخطة: **معتمدة ومنفَّذة بالكامل — الفحوص خضراء.**
> تاريخ الاعتماد: 2026-09-20. القرارات حُسمت مع المالك (س1–س3 + الخيار «أ» للشريط + تبسيط البيانات التجريبية).
> ملاحظات التنفيذ: أُضيف مساعد `withCourtPrefix` (بلا `\b` — لا يعمل عربيًا)؛ رسالة الفراغ بصيغة صادقة
> عامة تغطي الحجب والكفالة؛ اختبار قديم واحد (`ListPendingForHead…`) عُدّل لأصلين (كان يسطّر إنابتين
> على مال واحد — صار ممنوعًا).

## 1) القرارات المثبتة (نهائية)

1. **التعديل 1 — واجهة فقط في المنيب:** سطر الشرح الطويل يظهر في `DelegationsCard` (تظهر في المنيب فقط
   — `DocumentView.tsx:228-258`)؛ صفحة المناب (`DelegationStatusCard` + `SourceFileInfoCard`) بلا أي تغيير؛
   رسالة الخلفية `T1` («بانتظار الإتمام») بلا مساس؛ قرار `D1` قائم؛ الاختبار `:1498` لا يتغير.
2. **الكفالة خارج الإنابة كليًا:** «كفالة رواتب» لا تظهر أبدًا في قائمة أموال نافذة التسطير (إنشاءً وتعديلًا)،
   والخلفية ترفض أي `assetIds` يحويها برسالة صريحة. (أسقط هذا التباعدَ النصي القديم بين الدالتين.)
3. **الحجب:** أي إنابة سارية (بما فيها المعلّقة «بانتظار رئيس القسم») تحجب أموالها — إخفاء تام؛ التحرر
   تلقائي بالإتمام / شطب المناب (بجهتيه) / الاسترداد / حذف المعلّقة. بلا قاعدة اتحاد (البيانات تجريبية).
4. **الشريط:** يُبقى سطر «بانتظار الإتمام» القصير بجانب الشرح الجديد (شرح + سجل زمني) — مقصود (الخيار «أ»).

## 2) التعديل 1 — سطر الشرح (واجهة فقط، بلا هجرة)

- **الموضع:** `frontend/src/components/delegation/DelegationsCard.tsx` — سطر تفسيري لكل إنابة
  `مسجلة أصولًا` ولها رقم مناب (`targetFileNumber/Year`).
- **النص:** `بانتظار الإتمام — سُجّل الملف المناب أصولًا برقم أساس {N} دائرة تنفيذ {C}` من
  `targetFileNumber/targetFileYear` + `delegatedCourt` (الحيّة عبر `TargetCourt` في الـ`DTO`).
- **تطبيع البادئة:** مساعد أمامي (مُختبَر): تجريد أي بادئة `دائرة[ تنفيذ]*` زائدة ثم إضافة
  `دائرة تنفيذ` مرة واحدة — يمنع «دائرة دائرة تنفيذ القرداحة». مصفوفة اختبار:
  `دائرة تنفيذ دمشق` / `دائرة` / `تنفيذ دمشق` / `محكمة التنفيذ…` / بلا بادئة.
- **الاختبارات:** `DelegationsCard.test.tsx` — المسجلة تُظهر السطر؛ المعلّقة/المحالة لا تُظهره؛ بلا مضاعفة
  بادئة؛ المنفذة لا تُظهره.
- **استبدال لاحق معتمد (خطة المعالجة v2 — بند A2):** أُخفي السطر لأي مناب **نهائي**
  (مسترد/مشطوب/منفذ-إنابة عبر `targetTerminal` المحسوب خلفيًا) لا للمنفذ فقط، واشُترط
  الرقم **والسنة معًا** (لا أحدهما) — تجاوز مقصود لهذا البند يستبدله.

## 3) التعديل 2 — حجب الأموال (خلفية + واجهة، بلا هجرة)

### 3-1) القاعدة (تعريف واحد مشترك)

إنابة **حاجبة** ⟺ `Status != "منفذ إنابة"` **و** (`بلا مناب` أي معلّقة/قبل الاعتماد **أو** `المناب غير نهائي`).

- «غير نهائي» = ليس مشطوبًا (بجهتيه: `ExecStatus == "مشطوب"` أو `IsStruckOff(ExecutedStatus)`) ولا
  مستردًا (`Recovered`) ولا «منفذ إنابة» (`DelegationExecuted`). المناب الدرافت («محالة») يحجب.
- **التحرر تلقائي** (إتمام/شطب/استرداد/حذف) — بلا كود إضافي.

### 3-2) الخلفية (`DocumentDelegationService.cs`)

1. مساعد `IsAssetBlocking(d)` + `ValidateAssetsNotBlocked(source, assetIds, excludeDelegationId)`
   بمطابقة **واحد-لواحد** (نوع + وصف `AssetDisplay.Label`، استهلاك تدريجي) — **لا استبعاد أعمى** (التوأم
   السليم لا يُحجب).
2. رفض الكفالة أولًا: أي `assetId` من نوع `AssetKindCatalog.SalaryGuarantee` →
   `كفالة الرواتب لا يجري عليها إنابة` (قبل فحص الحجب).
3. يُستدعى قبل `ApplyDelegationAssets` في `Create` (`exclude = null` — `:88`) وفي `Update`
   (`exclude = self` — `:156`).
4. رسالة الحجب تسمّي الأموال: `الأموال التالية عليها إنابة سارية: {labels}`.
5. البيانات بلا استعلام جديد: `ListBySourceAsync` يحمل `Assets` + `TargetDocument` (`:51-53`).
6. `DTO`: حقل محسوب `BlocksAssets` بنفس المساعد داخل `ToDto` (المعلّقة بلا مناب → حاجبة؛
   ملاحظة: `ListPendingByBranchAsync` لا يحمّل `TargetDocument` — مقبول دلاليًا لنفس السبب).

### 3-3) الواجهة

1. `frontend/src/utils/delegationAssets.ts`: دالة `blockedAssetIds(delegations, assets, excludeId?)`
   بنفس منطق الواحد-لواحد + استبعاد الكفالة دائمًا من القائمة.
2. `frontend/src/pages/DocumentView.tsx`: يمرر للنافذة `assets` المفلترة (مستثنيًا إنابته عند التعديل)
   + راية `noAvailableAssets` لرسالة «لا توجد أموال متاحة للإنابة — جميعها محجوبة بإنابة سارية أو غير
   قابلة لها» عند الحجب الكامل — **بلا كشف أسماء**.
3. `frontend/src/components/delegation/DelegationFormModal.tsx`: يعرض القائمة المفلترة + نص الحالة
   الفارغة المميِّز (بلا أموال أصلًا ≠ الكل محجوب/مستبعد).

### 3-4) الاختبارات المطلوبة

- خلفية: رفض الإنشاء على مال محجوب (بتسميته)؛ رفض الكفالة إنشاءً وتعديلًا؛ سماح تعديل الذات على
  أموالها؛ التحرر بعد الإتمام / شطب المناب (بجهتيه) / الاسترداد؛ حجب المعلّقة؛ التوأم المكرر.
- واجهة: إخفاء الصفوف (كفالة + محجوبة)؛ نصا الحالة الفارغة؛ بقاء أموال الذات عند التعديل؛ سطر الشرح
  (ظهور/غياب/بادئة).
