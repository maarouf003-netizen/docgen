# Runbook — تراجع عن نسخة

## الأعراض/السياق

أخطاء 5xx متصاعدة، تعطّل تدفّق حرج، أو فشل فحص دخاني بعد نشر.

## التشخيص السريع

1. `/healthz` (العملية) و`/readyz` (القاعدة/outbox).
2. سجل الخادم: أول `ERROR` بعد وقت النشر، مع `TraceId` من جسم الخطأ (`ApiProblem.traceId`).
3. هل التغيير يمسّ قاعدة/هجرة؟ راجع `RUN_GUIDE.md` §9 وقائمة الهجرات المطبّقة.

## الإجراء

1. **أعد نشر النسخة السابقة** (الصورة/الإصدار السابق المعروف).
2. إن كانت الهجرة **expand-only** (كل هجرات هذا المستودع كذلك): لا حاجة لـ`Down`.
3. إن كانت البيانات تضررت: استعد النسخة الاحتياطية المأخوذة قبل النافذة، ثم أعد النشر.
4. أوقف أي `BackgroundService` مؤقتًا إن كان مصدر الضرر:
   `HeadAlerts:Outbox:Enabled=false`.

## التحقق

- `/readyz` يعود 200، والفحص الدخاني (دخول/بحث/تفاصيل/توليد) ناجح.
- لا أخطاء متكررة في السجل.

## التصعيد

- إن لم يتعافَ خلال 15 دقيقة: مالك النظام + مزوّد القاعدة.
- وثّق: الوقت، النسخة، السبب، الأثر، إجراء الاستعادة (postmortem بلا لوم).
