## 1. القياس قبل التطبيع

- الأمر: `dotnet format backend/DocGenerator.sln --verify-no-changes --no-restore`.
- النتيجة: **69 من 721 ملفًا** تحتاج تغييرًا (≈54 ثانية).
- تصنيف الفروق (بعد فحص `git diff` و`git diff -w`):
  1. **BOM** في أول سطر (`﻿using` ← `using`) — يخالف `charset = utf-8` المعلن.
  2. **سطر أخير مفقود** (`insert_final_newline = true`).
  3. **تهيئة كائنات/`with`/`else`** على سطر واحد ← سطر لكل عضو/فرع.
  4. **إزاحة عبارات المستوى الأعلى** داخل `try { }` في `Program.cs`.
- لا تغيير دلالي: كل الفروق تنسيقية (إعادة تقسيم أسطر/إزاحة/BOM/سطر أخير).

## 2. القرار والتنفيذ

- **تطبيع أساس واحد** بـ`dotnet format` (68 ملفًا، ~1,200 سطر تنسيقي) — لا إصلاحات
  منطقية، ولا لمس للهجرات (`generated_code = true` في `.editorconfig`).
- **`.gitattributes`** جديد: `* text=auto` مع `eol=lf` للامتدادات النصية (C#/مشاريع/
  JSON/YAML/Markdown) — يوحّد checkout بين Windows/Linux فلا تختلف نتيجة البوابة.
- **`.editorconfig`**: `end_of_line = lf` صريح، وتحديث التعليق ليعكس وجود البوابة.
- **بوابة `CI`**: خطوة `Format gate (dotnet format)` في وظيفة `backend` بعد البناء:
  `dotnet format backend/DocGenerator.sln --verify-no-changes --no-restore`.
