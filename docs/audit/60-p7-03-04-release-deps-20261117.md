# `P7-03` + `P7-04` — قائمة الإصدار وسياسة الاعتماديات — 2026-11-17

> PR: [#202](https://github.com/maarouf003-netizen/docgen/pull/202)
>
> نطاق هذه الجولة: قائمة إصدار موقّعة (توثيق تشغيلي)، وتفعيل تحديثات اعتماديات
> أسبوعية عبر Dependabot. لا تغيير في الكود أو الاعتماديات أو الهجرات.

## 1. ما أُضيف

1. **`docs/RELEASE_CHECKLIST.md`**: قبل النافذة (البوابات الثماني، `CHANGELOG`، نسخة
   احتياطية/استعادة، الهجرات وpreflight، متغيّرات `P2-03`، الاعتماديات، خطة التراجع)،
   أثناءها (سجل الهجرات ← التطبيق ← النشر ← صلاحيات التدقيق)، بعدها (health/ready/outbox،
   الرؤوس/الكوكيز/CORS، فحص دخاني، السجلات)، معايير التراجع، وحقول التوقيع.
2. **`.github/dependabot.yml`**:
   - `nuget` في `/backend` أسبوعيًا، تجميع minor/patch، سقف 5 PRs.
   - `npm` في `/frontend` أسبوعيًا، تجميع منفصل لـ`production`/`development`،
     `versioning-strategy: increase`، سقف 5.
   - `github-actions` أسبوعيًا، تجميع minor/patch، سقف 3.

## 2. القرارات

- **تجميع لا سيل PRs:** دفعة أسبوعية واحدة لكل فئة، وسقوف مفتوحة، لتقليل ضجيج المراجعة.
- **لا دمج تلقائي:** كل PR يمر بالبوابات الثماني (بما فيها `CodeQL` و`npm-audit-guard`)
  ومراجعة بشرية؛ التحديث ليس «آمنًا» بحكم كونه آليًا.
- **بوابات الاعتماديات هي الحكم:** `dependency-audit` (‎.NET) و`npm-audit-guard`
  (باستثناءات مؤقتة) و`dependency-review` (فرق الـPR) تبقى الفاصل، لا Dependabot وحده.
- **تحديثات الأمان إعداد مستودع:** Dependabot **security updates/alerts** يُفعّلها المالك
  من Settings → Code security؛ ملف `dependabot.yml` يغطي تحديثات الإصدارات الدورية فقط.

## 3. المراجعة النقدية

- **`packages.lock.json`:** أي PR لـNuGet يغيّر إصدارًا يجب أن يحدّث ملف القفل وإلا فشل
  `--locked-mode` (NU1004). تُراجع الدفعة الأولى يدويًا؛ لا نفترض أن Dependabot يحدّثه
  دائمًا بشكل صحيح لكل الحزم.
- **`.npmrc`/peer:** `openapi-typescript` غير مضاف؛ لا تغيير في حزمة الواجهة هنا.
- **`canary`:** غير مشمول في القائمة لأنه يحتاج `P5-04` (staging) — مذكور كحدّ صريح.
- **القائمة ليست أتمتة:** لا تمنع النشر تقنيًا؛ الالتزام إجرائي عبر التوقيع. أتمتتها
  (فحص بوابات/هجرات قبل tag) بند مستقل إن رغب المالك.
- **Dependabot Actions:** تحديث `actions/*` قد يغيّر سلوك CI؛ تجميع minor/patch يقلل
  الطلبات لكنه يزيد أثر الدفعة — المراجعة ضرورية.

## 4. التحقق

- لا كود/اختبارات/هجرات متغيّرة؛ البوابات الثماني تُشغَّل على الـPR كما هي.
- `dependabot.yml` رُوجع يدويًا وفق مخطط `version: 2` (لا مدقق محلي؛ GitHub يتحقق عند
  أول تشغيل مجدول/يدوي).
- روابط `docs/README` و`RELEASE_CHECKLIST` صحيحة نسبيًا.

## 5. الحدود

- **Security updates/alerts** تحتاج تفعيل المالك؛ بدونه لا تُفتح PRs أمنية تلقائية.
- **أول دفعة Dependabot** قد تحتاج إصلاح أقفال يدويًا؛ ليست «صيانة صفرية».
- **`canary`/`P5-04`** و`P5-06` (نسخ/DR) تبقى بوابات تشغيلية غير منفّذة.
- لا تغيير في `DoD` النهائي: «لا اعتماديات قديمة حرجة» يبقى هدفًا تراكميًا لا يُغلق بملف واحد.
