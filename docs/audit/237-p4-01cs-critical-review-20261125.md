## تدقيق التكافؤ حقل بحقل (عيّنة المسار الكامل)

مسار `GET /api/users/lawyers?branchId=…&mode=mine&includeInactive=…`:

`branchId`/`mode`/`includeInactive` (Query) ← `[Authorize(Roles = "head,subhead,manager,admin")]` ←
`CanManageBranchLawyers` (يرفض `Forbid`) ← محور الفرع: `IsHeadOrSubHead`
⇒ `User.GetBranchId()` وإلا `branchId` الممرَّر (ورئيس بلا فرع `403`) ←
`ListLawyersQuery(effectiveBranchId, mode, User.GetUserId(), User.GetSectionId(), IsHeadOrSubHead, includeInactive)`
← تطبيع الوضع (`"mine"` افتراضيًا) ورفض غير `mine`/`branch` ← (وضع `branch` أو غير رئيس)
`_users.ListLawyersAsync(branchId)` ثم فلترة/ترتيب/إسقاط ← (وضع `mine` لرئيس)
`_circuits.ListAsync` ← `_documents.ListOwnerIdsByCircuitIdsAsync`
← قائمة الفرع كاملة ← اتحاد القدامى بلا منشئ ← `includeInactive` ← قاعدة
(`ownerIds` ∪ `CreatedById == caller` ∪ بلا منشئ) ← `OrderBy(FullName)` ←
`Ok(List<LawyerListItemDto>)` كما هو.

- التطبيع: `(mode ?? "mine").Trim().ToLowerInvariant()` بنفس الترتيب، والرسالة نفسها.
- النطاق الفرعي للـendpoint ثابت (`Head_ListsLawyers_OnlyOwnBranch`) كما كان.
- الإسقاط: حقول `LawyerListItemDto` الثمانية بنفس الترتيب (`Id`، `Username`، `FullName`،
  `IsActive`، `BranchId`، `Branch?.Name`، `CreatedById`، `Version`).
