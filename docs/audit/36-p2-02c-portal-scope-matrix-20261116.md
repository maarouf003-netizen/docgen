# P2-02c — مصفوفة عزل نطاق المندوبين (البوابة) — 2026-11-16

> نطاق هذه الجولة: تثبيت عقد عزل نطاق المندوب الخارجي في بوابة المندوب — المورد
> الثاني بعد المستندات في `P2-02`. لا تغيير في كود التشغيل.

## 1. العقد المقيس

| الحالة | النتيجة |
|---|---|
| مندوب يطلب `/api/portal/my-scope` | `200` — مدخل جهته وحده (`entries.length = 1`) |
| مندوب يطلب `GET /api/portal/files` | `200` — ملفات نطاقه فقط (`totalCount` مطابق) |
| مندوب يطلب تفاصيل ملف **داخل** نطاقه | `200` |
| مندوب يطلب تفاصيل ملف **خارج** نطاقه | **`404`** (البوابة تُخفي الوجود خلافًا لـAPI الداخلي الذي يعيد `403`) |
| مندوب يطلب `files?entryId=<مدخل جهة أخرى>` | `403` برسالة (`UnauthorizedAccessException` مُعيَّنة) |
| مندوب بلا ربط جهة (`PortalEntryId = null`) | `200` بقائمة فارغة (`totalCount = 0`) |
| محامٍ/إداري على مسار البوابة | `403` |
| زائر بلا مصادقة | `401` |

**قرار موثّق:** الفرق بين `404` في البوابة و`403` في API الداخلي مقصود — المندوب طرف
خارجي، وإخفاء وجود الملف خارج نطاقه يمنع استكشاف البيانات بالمعرّفات.

## 2. كيف ثُبِّت

1. **قياس فعلي أولًا** (اختبار مؤقت حُذف قبل الالتزام): جهّز مجموعتَي جهات بمدخلين
   مختلفين، مندوبَين مربوطين بهما، مندوبًا بلا ربط، ومستندَين مرتبطين بالمدخلين عبر
   `ApplicantPublicEntities.RegistryId` (شرط `ScopePredicate`: الجهة نهائية وغير قيد
   المراجعة)، ثم طبع حالات كل طلب.
2. حُوّل القياس إلى `PortalScopeMatrixTests` (اختبار واحد، يجمع الانحرافات):
   - يتحقق من `my-scope` (مدخل واحد + اسم المديرية).
   - قوائم A/B: `totalCount = 1` والمعرّف المتوقع فقط.
   - التفاصيل: مملوك `200`، غير مملوك `404` (في الاتجاهين).
   - `entryId` أجنبي `403`، مندوب بلا ربط `200/0`، محامٍ `403`، زائر `401`.

## 3. التحقق

- `PortalScopeMatrixTests`: `1/1` ✅ (≈6 ثوانٍ).
- المجموعة الكاملة `Api` تُعاد قبل الدمج (الاختبار الجديد مضاف).
- لا تغيير في الكود ولا الهجرات.

## 4. حدود

- البوابة تغطي الملفات/النطاق فقط؛ مسارات البوابة الأخرى (المراسلات، التصدير،
  الإجراءات) مغطاة جزئيًا في اختباراتها القائمة؛ التوسعة الموصى بها: مصفوفة مراسلات
  بوابة بجهتين.
- العزل يعتمد على ربط `ApplicantPublicEntities/ExecutedPublicEntities.RegistryId`؛ أي
  تغيير في `ScopePredicate` يجب أن يُحدّث هذه المصفوفة بقرار.
- لا تغطي المصفوفة `staging`/`PostgreSQL` (يبقى `P1-01`).
