# `P4-01al` — إحالة ملفات الدائرة إلى Commands — 2026-11-24

> **قرار النطاق:** أثقل نقطة كتابة متبقية في `ExecutionCircuitService` بعد نقل الملكية:
> إفراغ دائرة كامل (تغيير مالك/دائرة/هوية ملفات + وقوعات ثلاثية + تدقيق حقلي وجماعي +
> تنبيه `Outbox`)، مع مفتاح عدم التكرار (`RF-011`) الذي يحيط بالمعاملة.

**حدود المعاملة (كما الأصل حرفيًا):** لا وسم `ITransactionalRequest`؛ حجز المفتاح
(`IdempotencyGuard.BeginAsync`) يسبق **كل** التحققات، ثم نواة داخل `_tx.RunAsync`،
ثم `CompleteAsync` باللقطة، و`ReleaseAsync` عند أي فشل. تحقّقات الفرع/الحمولة
(`حدد ملفًا واحدًا…`/`دائرة المصدر والهدف متماثلتان`) تبقى **خارج** المعاملة كما كانت.

## السلوك المحفوظ حرفيًا (داخل المعاملة، بالترتيب)

1. حجز المفتاح ببصمة `sourceCircuitId, fileIds(مرتبة), TargetLawyerId, TargetCircuitId, branchId, ownerSectionId`.
2. بوابة الفرع/المحافظة، ثم حمولة غير فارغة، ثم رفض تماثل الدائرتين.
3. `GetOwnedAsync` للمصدر والهدف (رسالتا الفرع/النطاق)، ورفض الهدف المعطّل.
4. تعطيل المصدر تلقائيًا (رفع نسخة) عند بدء الإفراغ.
5. المحامي الهدف: وجود/دور/تفعيل/فرع، ثم اسمه المعروض (احتياطي `Username`).
6. `ListByIdsForUpdateAsync` + رفض غير الموجود/المحذوف/خارج المصدر برسالتيه.
7. لكل ملف: تخطي المسند لمالكه الحالي بعدّاد، ثم طفرة (مالك/دائرة/محكمة معيارية/مسح الهوية/
   `NeedsRegistration`/`IsDraft=false`/نسخة/بحث) ووقعة `circuit-referred` بنصها،
   ووقعتا `source-file-moved`/`mirror-file-moved` بقاعدتيهما (C2)، وذيل تغيّر الوجهة.
8. حفظ ← إبطال كاش ← إعادة توجيه الواردة المعلقة (`PendingHead`) للدائرة الجديدة ← حفظ/إبطال.
9. تدقيق حقلي لكل ملف `refer_circuit_files`، ثم التدقيق الجماعي بنصه الكامل.
10. تنبيه المحامي المدمج عبر `Outbox` (`supersedePlan: null`) ← حفظ/إبطال ← عدّ المتبقي.
