## السلوك المحفوظ حرفيًا

1. إنابة غير موجودة ← `KeyNotFoundException("الإنابة غير موجودة")`.
2. الملكية أولًا (403) ثم الحالة (400) — برسالتيهما.
3. `ArchiveByDelegationAsync(…, DelegationKinds, "delegation_deleted")` ثم الحذف.
4. تدقيق `delete_delegation`: `حذف إنابة (رقم …) إلى …`.
