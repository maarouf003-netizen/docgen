## الملخص

- **العد**: `CRITICAL` صفر — `HIGH` نتيجة واحدة — `MEDIUM` خمس نتائج — `LOW` تسع نتائج. المجموع 15 (`INT-001` … `INT-015`).
- **أهم المخاطر بلغة plain**:
  1. رقما أساس متطابقان (نفس الدائرة + الرقم + النوع + السنة) يمكن إدخالهما معًا بلا أي رفض —
     لا قيد قاعدة ولا فحص كود (`INT-001` HIGH). هذا يخالف قاعدة الوحدانية الصريحة في السياق §4.
  2. محاميان يحرران نفس الملف معًا: الأخير يمحو الأول بصمت — لا رمز تزامن في النظام كله (`INT-002`)،
     وانتقالا حالة متزامنان: الأخير يربح مع ضياع انتقال (`INT-012`).
  3. مبالغ بعملات مختلفة تُجمع في رقم واحد في إحصاءين (`INT-003`)، وعملات غير معروفة تُسقَط من
     الإحصاءات بصمت (`INT-004`) — كلاهما سؤال عمل قبل أن يكون خللًا.
  4. النقر المزدوج/إعادة الإرسال تُكرر الأثر (ملف ثانٍ، دمج ثانٍ، `PrintCount++` زائد) — لا مفاتيح
     عدم تكرار (`INT-007`).
  5. الملف المحذوف منطقيًا يمكن إعادة استعمال رقمه ثم استعادته → تكرار ظاهري (`INT-008`)،
     والتدقيق نفسه يُكتب بحفظتين غير ذريتين بذاتهما (`INT-006`) وقابل للكتابة تقنيًا (انظر `SEC-008`).
- **الخبر السار (VERIFIED)**: كل سير حرج داخل `_tx.RunAsync` واحد (إنشاء/تعديل/حالة/تدوير/نقل/إنابة/
  استئناف/مراسلات/دمج/استيراد)؛ النقل شرطي ذري (`rows==0 → 409`)؛ حجوزات الأصول محمية بقيد فريد +
  التقاط تعارض؛ أرقام المراسلات/المطالعة فريدة مع إعادة توليد؛ كل النقود `decimal(20,2)` بلا
  `double/float`؛ الجمع الرئيسي لكل عملة على حدة؛ `SplitQuery` عمومي يمنع الانفجار الديكارتي؛
  الهجرات الأخيرة نظيفة وموثقة؛ لا `SQL` خام عدا إدراج معامَل واحد لمحدد الدخول.

   `BQ-030`) + نطاق التطبيع العربي (`INT-014` ← `BQ-034`) + قوائم `Check` (`INT-015` ← `BQ-035`) +
   قاعدة سباق الحالة (`INT-012` ← `BQ-033`) + أولوية مفاتيح عدم التكرار (`INT-007` ← `BQ-032`).
3. **ثم الهجرات (دفعة واحدة مخططة)**: قيد الترقيم الجزئي (`INT-001`) + `rowversion` (`INT-002` ومعه
