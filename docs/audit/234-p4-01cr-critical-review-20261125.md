## تدقيق التكافؤ حقل بحقل (عيّنة المسار الكامل)

مسار `GET /api/documents/referred-to-start/list` (قائمة «محال الى البداية» المسقطة):

`q`/`page`/`perPage`/`cursor` (Query) ← `[Authorize(Roles = …)]` ←
`_authorization.ResolveListScope(User)` (بلا قدرة إضافية، كما كان) ←
`SearchReferredToStartDocumentListQuery` ← `_cursorCodec.DecodeOptional(cursor, StartReferralDate)`
← `IDocumentRepository.SearchReferredToStartListAsync(q, VisibleBranchId, VisibleUserId, page,
perPage, ct, OwnerSectionId, keyset)` ← `DocumentSearchHelpers.BuildListResult(rows, total,
cursor is null ? page : 1, perPage, NextCursor(StartReferralDate, …), clock, timeZone)` ←
`Ok(PagedResult<DocumentListItemDto>)` كما هو.

- الترقيم: `Math.Max(1, Page)` و`Math.Clamp(PerPage, 1, 100)` بنفس التسلسل قبل الاستعلام.
- المؤشر: نفس النوع ونفس الصف الأخير (`rows[^1]`) ونفس `Encode(kind, sortValue, last.Id)`.
- السنة المعروضة: `ServerClock.CurrentYear(clock, timeZone)` بنفس الساعة/المنطقة المحقونتين.
- `NextCursor` يُعاد `null` عند `!hasMore || rows.Count == 0` — كما هو.

## تدقيق عدّ المعالجات وعدم التكرار

- 73 تسجيل `IQueryHandler<,>` + 118 تسجيل `ICommandHandler<,>` = **191**، مقابل **191**
  صنف معالج في `Application` → 0 غير مسجَّل و0 مكرر.
- أُضيفت اثنا عشر سطرًا متجاورًا بعد استعلامات المستند السبعة بلا تكرار، وحُذف سطر
  `IDocumentSearchService`، واختبار `DocumentSearchHandlerRegistrationTests` يثبت
  تسجيل كل عقد مرة واحدة بالنوع الدقيق.
- لم يُسجَّل أي معالج في طبقة `Api`؛ خط الأنابيب في `Application` فقط.
