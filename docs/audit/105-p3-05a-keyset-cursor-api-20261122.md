# `P3-05a` — Keyset cursor API للقوائم الكبيرة — 2026-11-22

> **النطاق:** المرحلة الإضافية غير الكاسرة من `P3-05`: إضافة `cursor` اختياري
> و`nextCursor` إلى `/documents/list` والقوائم الخمس `/…/list`، مع إبقاء
> `page`/`perPage` كما هي. **لا تغيير كاسر، ولا تغيير في الواجهة بعد، ولا هجرة.**

## 1. التصميم

1. **`KeysetCursor`** (Application): `Kind` + `SortValue` + `Id`، وأنواع مفاتيح
   لكل قائمة (`document.created/deleted/struck/executed/referred/reminders`).
2. **`KeysetCursorCodec`** (Infrastructure): ترميز `Base64Url(payload).Base64Url(HMAC)`
   بمفتاح مشتق من `Jwt:Secret` بسياق منفصل (`docgen.keyset.v1`) — التوقيع حارس
   سلامة وربط بنوع القائمة، لا حدود صلاحية.
3. **`PagedResult<T>.NextCursor`**: حقل إضافي `string?` — `null` في آخر صفحة أو
   للقوائم الإدارية الصغيرة.
4. **المستودع**: كل قائمة مُسقَطة تقبل `KeysetCursor?`:
   - `Skip(0)` + شرط keyset بدل الإزاحة عند وجود المؤشر.
   - `Take(perPage + 1)` دائمًا لكشف وجود صفحة تالية ثم قصّ الصف الزائد.
   - `CountAsync` يبقى على الاستعلام المفلتر كاملًا (العدّ الكلي للعرض).
   - ترتيب `NULL` مطابق لسلوك PostgreSQL (`DESC` ⇒ NULL أولًا) في
     `DeletedAt`/`StruckOffDate`، و`StartReferralDate` يبقي NULL آخرًا كما كان.
   - تذكيرات الشطب: مؤشر تصاعدي على `(LastActivity, Id)`.
5. **الخدمة/المتحكم**: `cursor` خام يُفك بعد فحص الدور/النطاق (400 عربي عند
   التلف أو اختلاف النوع)، والاستجابة تحمل `nextCursor` من آخر صف.
6. **`OpenAPI`/`generated.ts`**: معامل `cursor` وحقل `nextCursor` أُضيفا وأُعيد
   توليدهما؛ بيان عقد `PagedResult` في `head-alert-contracts.json` حُدّث.

## 2. الأمان والحدود

- المؤشر **موقّع** ومربوط بنوع القائمة؛ تلفه أو استخدامه في قائمة أخرى ⇒ `400`.
- النطاق والصلاحيات والفلاتر تُطبَّق خادميًا في كل طلب؛ المؤشر لا يمنح وصولًا.
- المؤشر **غير مربوط بمجموعة الفلاتر**: إعادة استخدامه بعد تغيير الفلتر قد
  تُنتج ترتيبًا غير متوقع (لا تسريب). يُوثَّق كحدّ معروف للمرحلة 1أ.
- `TotalCount` لا يزال يُحسب كاملًا (كلفة العدّ قائمة)؛ ما أُزيل هو مسح
  `OFFSET` العميق فقط.
- PostgreSQL هو المزوّد الوحيد في التشغيل (`ADR-0001`)، ودلالات NULL أعلاه
  مقيَّدة به صراحةً.

## 3. ما لم يُنفَّذ بعد (1ب)

- **واجهة القائمة الرئيسية** ما زالت على `page`/`perPage`. تحويلها إلى «تحميل
  المزيد» يتطلب قرارًا في **استعادة موضع القائمة** المحفوظ في الجلسة
  (`listSession.ts`): إما حفظ سلسلة المؤشرات وإعادة تشغيلها عند العودة، أو
  قبول العودة إلى أعلى القائمة. لا يُغيَّر سلوك قائم بلا قرار مالك.
- القوائم الأرشيفية الصغيرة تبقى على الترقيم العادي (كما في الخطة: offset
  للإداريات الصغيرة).
