## تدقيق التكافؤ حقل بحقل (عيّنة المسار الكامل)

مسار `GET /api/execution-circuits/stats?branchId=…`:

`branchId` (Query) ← `[Authorize(Roles = "manager,admin,head,subhead")]` ←
`HasFullAccess` (مدير/مشرف): `GetCircuitStatsQuery(branchId, null, true)`، وإلا
`RequireOwnerScope` (`CanManageExecutionCircuits` + claim الفرع + شعبة رئيس الشعبة)
⇒ `GetCircuitStatsQuery(own, ownerSectionId, false)` ←
`ReferenceDataQueries.ListCircuitsAsync` (كاش `circuits`/"all") ← فلترة الفرع ثم
النطاق عند غياب الوصول الكامل ← `OrderBy(BranchId).ThenBy(Name)` ←
`ReferenceDataQueries.ListBranchesAsync`/`ListSectionsAsync` (كاش) ←
`CountByCircuitsAsync`/`CountLawyersByCircuitsAsync` (حيّة) ← صفوف
`CircuitStatsDto` بنفس الحقول الأحد عشر وترتيبها ← صف «بلا دائرة» عند
`ownerSectionId is null` و`fileCount > 0` (`CircuitId = 0` و`"بلا دائرة"`) ←
`Ok(List<CircuitStatsDto>)` كما هو.

- التصدير `stats/export` يمرّ بالمسار نفسه ثم `BuildCircuitStatsWorkbook(rows)` بنفس
  العمود الشعبة ونفس اسم الملف (`ServerClock.TodayString` بالمنطقة المحقونة).
- **النطاق الفرعي** ثابت (`Head_Stats_OwnSectionOnly` كما كان).
- **الإسقاط:** حقول `CircuitStatsDto` بنفس الترتيب
  (`Id`، `Name`، `BranchId`، `BranchName`، `IsActive`، `FileCount`، `LawyerCount`،
  `PendingCount`، `SectionId`، `SectionName`، `Version`).
