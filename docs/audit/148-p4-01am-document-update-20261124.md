# `P4-01am` — تعديل المستند إلى Commands — 2026-11-24

> **قرار النطاق:** أثقل نقطة كتابة في `DocumentService`: تعديل ملف كامل بكل مشتقاته
> (هوية/دائرة/تسجيل)، وحارسَي الانتقال المنفّذ والإنابة، والمرآة والتنبيهات والوقوعات،
> داخل شبكتَي التزامن والترقيم ومعاملة واحدة. نُقلت في PR مستقل بمراجعة موسّعة.

## قبل/بعد

| قبل | بعد |
|---|---|
| `DocumentService.UpdateAsync` + `ValidateExecutedTransitionOnEdit` (في `DocumentService.Crud.cs`) | `UpdateDocumentCommand` + معالج يملك المعاملة والتدقيق وشبكتي التزامن/الترقيم |
| ضمن عقد `IDocumentService` | أُزيلت من العقد والتنفيذ (لا مستدعٍ غير المتحكم والاختبارات) |
| `ApplyRequest` خاصةً بالخدمة | `DocumentService.ApplyRequest` **داخلية مشتركة** (الإنشاء + التعديل) بلا تكرار |
| `ApplyRegistrationDate` نسخة واحدة تعتمد `_registrationDates` | حِمل زائد `static` يأخذ المستودع صراحةً، والخدمة تُفوّض إليه (منطق مطابق) |
| حارس الانتقال المنفّذ داخل `Crud.cs` | داخل المعالج (المستدعي الوحيد له) |
| المتحكم ينادي الخدمة مباشرة | المتحكم ينادي `ICommandHandler<UpdateDocumentCommand, DocumentResponse?>` المسجَّل صراحةً |

**حدود المعاملة (كما الأصل حرفيًا):** لا وسم `ITransactionalRequest`؛ التحققات الثقيلة
(المدققون + حارسا الانتقال/الإنابة + تفرد الترقيم + فحص التزامن المبكر) تسبق المعاملة،
ثم `WithConcurrencyGuardAsync(WithNumberGuardAsync(_tx.RunAsync(...)))` كما هو،
و`UserId` يبقى `int?` بلا تغيير.

## السلوك المحفوظ حرفيًا (بالترتيب)

1. قراءة الملف (غير موجود ← `null` بلا استثناء).
2. المدققون: التطبيع، الصفة، المنفَّذ، عدد الكفلاء، تاريخ التسجيل، السنة غير المستقبلية،
   حصر الممثل/الورثة، والملاحق.
3. لقطة «قبل»، وحالة الشطب، وحارس الانتقال المنفّذ، وحارس تعديل المناب، وقفل الحجز/الأصل.
4. حفظ القديم (دائرة/محكمة/معيار/`NeedsRegistration`) ← `ApplyRequest` ← قاعدة تبديل
   الدائرة الثلاثية ← إسقاط `NeedsRegistration` ← المشتقات ← تاريخ التسجيل ← `UpdatedAt`.
5. تفرد رقم الملف بتوقيع الدائرة، ثم فحص التزامن المبكر (409 ودية).
6. المعاملة: التجديد/الشطب، الحفظ، مزامنة سجل القيد، وقوعتا تبديل الدائرة، مزامنة
   اللقطات، المرآة، تدقيق حقلي `update` بنصه، تنبيهات المرآة/الإضافات، ثم البذور.
7. الإسقاط `DocumentResponse.FromEntity(doc, CurrentYear())`.
