- `query` فراغ بعد `trim`: يُعاد كل الصفوف دون تصفية.
- `reminder` غائب في وقوع غير شخصي: الصف يعيد `null` (لا واجهة مكسورة).
- عنوان استئناف مفقود: يظهر `استئناف <id>` كما كان.
- نص إجراء فارغ بعد التجريد: لا يُعرض سطر فارغ.
- تعديل تذكير له `recurrenceEnd`: يظهر «إبقاء النهاية الحالية» و«إزالة النهاية».
