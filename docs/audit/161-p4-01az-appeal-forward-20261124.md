> **قرار النطاق:** إغلاق «حالة الاستئناف» بنقل الإحالة (`ForwardAsync`) والتراجع
> (`RecallForwardAsync`) مع تنبيهيهما وترجمة سباق التزامن إلى 409 ودية.

**حدود المعاملة:** كما الأصل — كل التحقق خارج المعاملة، ثم معاملة واحدة تغلق بـ`catch`
تعارض التزامن حولها (409 ودية)، بلا وسم `ITransactionalRequest`.

## السلوك المحفوظ حرفيًا

1. الإحالة: منظور + غير مسند + غير محال + النسخة + رئيس شعبة ضمن الفرع/الشعبة +
   وجود رئيس قسم مفعّل + حدّ السبب (1000) برسائله.
2. الحالة `ForwardedToHead` والسبب، رفع النسخة، تنبيه الرئيس، وتدقيق:
   `يرجى التفضل بإسناد الاستئناف (ملف … — محال من …)[ — السبب: …]`.
3. التراجع: منظور + غير مسند + إحالة مفتوحة + المحيل أو رئيس قسم الفرع؛ تصفير الحالة،
   وتنبيه/أرشفة، وتدقيق `استرجع المحيل…` / `أعاد رئيس القسم…`.
4. `catch IsConcurrencyViolation` حول المعاملة كلها في المسارين.
