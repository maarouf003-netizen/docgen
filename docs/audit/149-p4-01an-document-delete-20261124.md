# `P4-01an` — حذف المستند المنطقي إلى Commands — 2026-11-24

> **قرار النطاق:** آخر نقطة كتابة باقية في `DocumentService` بعد `Create`/`Update`:
> الحذف المنطقي بحرّاس الإنابة/الاستئناف وإلغاء صفوف الأرقام قبل رفع العلم.

## قبل/بعد

| قبل | بعد |
|---|---|
| `DocumentService.DeleteAsync` (في `DocumentService.Crud.cs`) | `DeleteDocumentCommand` + معالج يملك المعاملة والتدقيق |
| ضمن عقد `IDocumentService` | أُزيلت من العقد والتنفيذ (لا مستدعٍ غير المتحكم والاختبارات) |
| الخدمة تحمل `IAppealRepository` لهذا المسار فقط | أُزيل من الحقول والتركيب، وحُدّث مصنع الاختبار |
| المتحكم ينادي الخدمة مباشرة | المتحكم ينادي `ICommandHandler<DeleteDocumentCommand, bool>` المسجَّل صراحةً |

**حدود المعاملة (كما الأصل):** الحرّاس الثلاثة قبل المعاملة، ثم `_tx.RunAsync` واحدة:
إلغاء صفوف الأرقام (`document-deleted`) ← رفع علم الحذف/الطوابع/النسخة ← حفظ ← تدقيق.

## السلوك المحفوظ حرفيًا

1. ملف غير موجود ← `false` (404) بلا استثناء.
2. حارس الإنابة الصادرة: `لا يمكن حذف الملف المنيب لوجود إنابة صادرة عنه`.
3. حارس الإنابة المرتبطة: `لا يمكن حذف الملف المناب لوجود إنابة مرتبطة به`.
4. حارس الاستئناف: `لا يمكن حذف الملف لوجود استئناف مرتبط به`.
5. إلغاء الأرقام **قبل** العلم (لتبقى الصفوف مرئية لاستعلام الإلغاء)، ثم
   `IsDeleted/DeletedAt/UpdatedAt/Version++` ← حفظ ← تدقيق `delete` بنصه:
   `حذف المستند (رقم …) — المنفذ عليه: …`.
