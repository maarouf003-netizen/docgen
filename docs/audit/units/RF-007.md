# `RF-007` — تضييق قراءة التدقيق بنطاق الفرع

> الفرع: `refactor/RF-007-auditscope`. الحالة: موجز مكتوب (Step 2) — بانتظار التنفيذ والتحقق.

## Objective

رئيس القسم يرى تدقيق فرعه فقط: صفوف مستندات فرعه (عبر `DocumentId → BranchId`) وصفوف فاعلي
فرعه (عبر `UserName → Users.BranchId`). المدير/المشرف بلا تغيير (الكل).

## Current problem

`AuditLogRepository.SearchAsync` (`:14-43`) بلا أي ترشيح نطاق، والمتحكم لا يمرر نطاقًا
(`AuditLogsController.cs:18-25`) — رئيس دمشق يرى تدقيق حلب بما فيه التفاصيل المالية والقضائية
(`SEC-013` HIGH).

## Evidence

  `AuditLogRepository.cs:14-43`.
- النمط القائم: `scopeBranchId = IsHead ? ... : null` في `UserManagementController.cs:132,154`
  و`visibleBranch` في `DocumentsController.cs:107+`.
- `AuditLog` بلا `BranchId` (`AuditLog.cs:9` مجرد `DocumentId?`) — النسب عبر جدولين (أدناه).

## Files affected

- `AuditLogsController.cs` (تمرير `scopeBranchId` للرئيس فقط).
