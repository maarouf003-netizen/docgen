# `RF-015` — فصل مجاميع العملات + سلة «أخرى» (`INT-003` + `INT-004` ← `BQ-029` + `BQ-030`)

> الفرع: `refactor/RF-015-currency` (تراكمي). الحالة: منفذ ومُتحقق ومُثبت (كُتب الموجز لاحقًا لاستكمال العرف).

## Objective

إغلاق الجمع المختلط العملات في الإحصاءات + إسقاط العملات غير المعروفة بصمت — حسب قراري المالك.

## Current problem

- `executedAgainstAmount` و`depositExecutedAmount` يجمعان `Paid1+2+3` في `decimal` واحد بلا فصل
  عملة (`StatisticsRepository.cs:491-519`) — `INT-003` (`BQ-029`).
- العملات خارج الثلاث تُسقَط من الإحصاء بصمت (`AddAmount`) — `INT-004` (`BQ-030`).

## Evidence

- قرار المالك (`business-questions.md`): فصل لكل عملة كالبقية (`ToCurrencyAmounts`) + `SalePrice`
  ليرة دائمًا (`BQ-029`)؛ سلة «أخرى» مع تنبيه مراجعة (`BQ-030`).

## Files affected

- خلفية: `StatsDtos.cs` (حقلا `ExecutedAgainstAmounts`/`DepositExecutedAmounts` الجديدان؛ `decimal`
  القائم = سلة الليرة للتوافق) + `StatisticsRepository.cs` (سلال `AddAmount` للمدفوع/المودع بعملاته؛
  `ManagerStatRow` + الاستعلامان يشملان عملات المدفوع الثلاث؛ المجهولة ← سلة «أخرى» أخيرًا).
- واجهة: `types/index.ts` (الحقلان اختياريان لتوافق الحمولات) + `StatsCards.tsx` (عرض الفصل مع
  fallback، وتنبيه `role="note"` عند «أخرى») + `CurrencyAmountList.tsx` (تنبيه «أخرى»).
- اختبارات: 3 خلفية (فصل منفذ/إيداع + «أخرى» لا تُسقَط) + 1 واجهة (عرض الفصل).

## Business behavior affected

مقصود: `decimal` القديم كان مجموعًا مختلطًا وأصبح سلة ليرة فقط؛ الواجهة تعرض الفصل الكامل.
