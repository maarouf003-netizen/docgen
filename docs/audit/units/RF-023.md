# `RF-023` — تفكيك نوافذ مراجعة السجل لمكونات (`ARC-009`)

> الفرع: `refactor/RF-015-currency` (تراكمي). الحالة: منفذ ومُتحقق — بانتظار التثبيت.

## Objective

حدود مكونات واضحة لصفحة المراجعة (1515 سطرًا): النوافذ والأجزاء المشتركة ملفات مستقلة —
بلا أي تغيير سلوكي أو بصري.

## Current problem

`EntityRegistryReviewManagement.tsx` يضم 3 نوافذ أفعال + صدفة عامة + حقول مرجع + منسق
عدّات — كلها محلية بلا إعادة استعمال — `ARC-009` (الاتجاه القائم: 8 مكونات مستخرجة مسبقًا
في `components/entity/` مع اختباراتها).

## Evidence

- النطاق المختار: كل ما هو معزول الحالة والقابل للنقل الحرفي (النوافذ الثلاث + الصدفة +
  حقول المرجع + المشترك) — أما `EditEntityTab`/`AddEntityTab` (الحالة والأوركسترا) و`TabButton`/
  `MenuItem`/`useDebounced` (صفحة-محلية) فبقيت في الصفحة عمدًا.
- خارج النطاق الموثق: `DocumentForm` (1193 — مقسّم مسبقًا لأقسام `Applicant/Executed` وحقول
  مشتركة؛ الباقي حالة ومعالجات لا مكونات — التفكيك الأعمق جراحة `props` بلا عائد) و`viewFormat`
  (المحاذاة مع `EffectiveFileIdentity` مثبتة مسبقًا: `identityFileNumber` + قاعدة الزوج الواحد).

## Files affected

- جديدة `components/entity/`: `reviewShared.ts` (منسق `f` + نوع `GroupPick`) ·
  `DecreeFields.tsx` (المناداة + `FreeDateInput` + `DECREE_KINDS`) ·
  `ReviewActionModal.tsx` (الصدفة + زر الإغلاق) · `RenameGroupModal.tsx` ·
  `MergeBranchesModal.tsx` · `AbolishBranchModal.tsx` (+ `AbolishPreviewBox`) — نقل حرفي
  مع `export` وإعادة تسمية توضيحية فقط (`RenameModal` → `RenameGroupModal` …).
- `EntityRegistryReviewManagement.tsx`: حذف المنقول + استيراد البدائل + 3 أسطر `JSX` مُعاد
  تسميتها + تقليم 5 استيرادات ميتة (كشفها `tsc`).
- اختبارات جديدة (على عرف `UnifyNamesModal.test`): 11 حالة (عرض/معاينة/تحقق/تنفيذ/خطأ)
  للنوافذ الثلاث.
