## Current problem

الفروع) — كتابة مستقبلية خاطئة تُنتج حالة يتيمة تكسر الفلاتر والإحصاءات بصمت.

- القيم المخزنة فعلًا: `ExecStatus` (السبع + `مشطوب`)، `ExecSubStatus` (الفرعيتان)،
  `ExecutedStatus` (الثلاث)، `GeneralEntitySide` (الثلاث)، حالتا الإنابة والاستئناف.
- `NULL` تجتاز `Check` تلقائيًا (لا حاجة لاستثنائها).
