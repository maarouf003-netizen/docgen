# P2-02f — مصفوفة عزل الاستئناف وإصلاح دلالة أخطائه — 2026-11-16

> نطاق هذه الجولة: المورد الرابع في `P2-02` (الاستئناف) — تثبيت عزل القراءة، وإصلاح
> نفس ثغرة الدلالة التي ظهرت في الإنابة (`400` بدل `403/404`) قبل تثبيت المصفوفة.

## 1. العقد المقيس (قبل الإصلاح)

| الفاعل | تفاصيل الاستئناف | استئنافات المستند | تعديل/حذف |
|---|---|---|---|
| المالك (محامٍ) | `200` | `200` + عنصر | مسموح (قيد الحالة) |
| رئيس / مدير / مشرف | `200` | `200` + عنصر | حسب الدور/الإسناد |
| محامٍ آخر (نفس الفرع) | `403` | `403` | **`400`** ← ثغرة |
| محامٍ آخر (فرع آخر) | `403` | `403` | **`400`** ← ثغرة |

## 2. الثغرة والإصلاح

- `EnsurePendingByCreator` كان يرمي `ArgumentException` لفحص الملكية ⇒ `400`.
- `EnsureAssignedFollower` كان يرمي `ArgumentException` لمن ليس مسندًا إليه ⇒ `400`.
- `UpdateAsync`/`DeleteAsync` كانا `ArgumentException("الاستئناف غير موجود")` ⇒ `400`.

الإصلاح (بنفس نمط `P2-02e`):

| الموضع | قبل | بعد |
|---|---|---|
| ملكية المصدر (`CreateAsync`) | `400` | `403` |
| مصدر مفقود | `400` | `404` |
| استئناف مفقود (`Update/Delete`) | `400` | `404` |
| `EnsurePendingByCreator` — الملكية | `400` (بعد فحص الحالة) | `403` **(قبل فحص الحالة)** |
| `EnsureAssignedFollower` | `400` | `403` |
| حالة غير معلّقة/مسندة | `400` | `400` (خطأ حالة عمل) |

## 3. المصفوفة المثبَّتة

`AppealScopeMatrixTests` (اختبار واحد يجمع الانحرافات): مالك/رئيس/مدير/مشرف `200` +
عنصر في القائمة؛ محامٍ آخر (نفس الفرع أو فرعه) `403` للتفاصيل والقائمة؛ تعديل/حذف الغير
`403` في الاتجاهين؛ معرّف مفقود `404`؛ والاستئناف يبقى للمالك بعد المحاولات.
