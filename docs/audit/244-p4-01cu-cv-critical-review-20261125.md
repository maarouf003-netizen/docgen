## تدقيق التكافؤ حقل بحقل (عيّنة المسار الكامل)

مسار `GET /api/forum/messages?limit=30&before=&after=`:

`limit`/`before`/`after` (Query) ← `[Authorize(Roles = "lawyer,head,subhead,manager,admin")]`
← `User.GetUserId()` ← `ListForumMessagesQuery(UserId, limit, before, after)` ← تقويم
`limit < 1 || > 100 ⇒ 30` ← `_forum.ListSliceAsync(limit, before, after)` ←
`CountReadsAsync` لرسائل الفاعل فقط ← `ForumService.ToDto` (16 حقلًا بنفس الترتيب) ←
`HasOlderAsync(dtos[0].Id)` ← `ForumMessagesPageDto(items, hasOlder)` ← `Ok(...)` كما هو.

مسار `GET /api/app-suggestions/{id}`: `IsAdmin` يحدد `senderId = null` أو `UserId`؛
المعالج يجلب `GetByIdWithSenderAsync`، الغائب `null`، وغير المملوك `null` (404 بلا كشف)،
و`ToDto(includeSender)` كما هو.

مسار `GET /api/personal-reminders/{id}`: `CanManage` قبل الاستعلام، ثم ملكية
`reminder.LawyerId == userId` وإلا `null` (404)، و`ToDto` بتواريخ `yyyy-MM-dd` كما هو.
