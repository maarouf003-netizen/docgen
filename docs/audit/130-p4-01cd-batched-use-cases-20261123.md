| قبل | بعد |
|---|---|
| `ReviewLetterService.MarkRepliesSeenAsync` تفتح المعاملة وتحفظ | `MarkReviewRepliesSeenCommand` + معالج يملك المعاملة عبر `ITransactionalRequest` |
| `_tx`/`_uow` مستخدمان في المسار | المعالج يعتمد `IReviewLetterRepository` + `IUnitOfWork` فقط |
| ضمن عقد `IReviewLetterService` | أُزيل من العقد (لا مستدعي غير المتحكم) |

- السلوك محفوظ: `KeyNotFoundException` عند الغياب، `UnauthorizedAccessException` لغير
  محامي الكتاب، `true` بلا حفظ عند عدم وجود ردود غير مقروءة، وتعليم كل ردود
  `KindReply` غير المقروءة.
