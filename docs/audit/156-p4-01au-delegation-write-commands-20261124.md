## السلوك المحفوظ حرفيًا

1. حرّاس المصدر (وجود/صفة/ملكية/انتظار إعادة القيد) برسائلها، والتحقق وبناء الحقول.
2. استهداف اعتماد التنبيه (فرع/مالك) ونص `DelegationPendingApproval` كما هو.
3. القراءة الطازجة بلا تتبع ← تطهير الحجوزات ← حارس الأصول ← اللقطة/الطفرة ← حجز
   المستهلَك ← `Outbox` (بلا خطة استبدال عند الإنشاء، وبخطة `delegation_updated` عند التعديل).
4. ترجمة انتهاك القيد إلى رسالة الحجب نفسها، ثم التدقيق `create_delegation`/`update_delegation`
   بالنصين الكاملين، والإسقاط بالسنة الخادمية.
