## السلوك المحفوظ حرفيًا

1. بصمة `sourceLawyerId, targetLawyerId, scopeBranchId, ownerSectionId` واسم العملية
   `documents.transfer-all`.
2. تحققات المصدر (وجود/دور/النفس/الفرع) والهدف (وجود/دور/تفعيل/الفرع) برسائلها.
3. لا ملفات ← `0` بلا كتابة.
4. النقل الذرّي، وتطابق العدد وإلا `DocumentConflictException` برسالتها.
5. سجل تعاقب + تدقيق لكل ملف: `تم إحالة هذا الملف إلى المحامي: … بتاريخ … — المنفذ عليه: …`.
6. مزامنة المناب ثم `SyncPendingAlertsAfterTransferAsync` عند وجود `ActorUserId`.
