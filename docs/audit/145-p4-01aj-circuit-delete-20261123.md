## السلوك المحفوظ حرفيًا (الترتيب داخل معاملة واحدة)

1. فحص الفرع/المحافظة، ثم `GetOwnedAsync` (فرع + نطاق ملكية).
2. حارس الملفات الحيّة: `لا يمكن حذف الدائرة — أفرغها أولًا (بها {n} ملفًا)`.
3. حارس الإنابات الواردة المعلقة (متجاوزًا فلتر المصدر المحذوف).
4. **فصل الوارد قبل التطهير:** `DelegatedCircuitId=null` مع إبقاء الاسم النصي،
   وأي `PendingHead` يوقف العملية بـ`409`.
5. تطهير سلة المحذوفات: صفوف أرقام الأساس (عبر `IDocumentBaseNumberRepository` أو
   البديل)، أرشفة التنبيهات المرتبطة (`IsArchived/ArchivedAt`)، ثم الحذف الفيزيائي
   للمستندات.
6. إزالة الدائرة ← حفظ ← إبطال كاش ← تدقيق `delete_circuit` بنصه:
   `حذف دائرة التنفيذ «…» مع فك {m} إنابة مكتملة عن مرجعها (الاسم محفوظ)[، وطُهِّر نهائيًا {n} ملفًا محذوفًا]`.
