# P2-02d — مصفوفة عزل الإنابة (قراءة) وثغرة دلالة مكتشفة — 2026-11-16

> نطاق هذه الجولة: تثبيت عقد قراءة إنابات المستند عبر الأدوار/الفروع، وتوثيق ثغرة دلالة
> في مسارات الكتابة بدل إصلاحها داخل PR اختباري. لا تغيير في كود التشغيل.

## 1. العقد المثبَّت (مقيس فعليًا)

| الفاعل | `GET /api/documents/{id}/delegations` | `GET /api/delegations/pending` + `pending-count` |
|---|---|---|
| مالك المستند (محامٍ) | `200` + عنصر الإنابة | `403` |
| رئيس | `200` + عنصر الإنابة | `200` |
| مدير | `200` + عنصر الإنابة | `403` |
| مشرف | `200` + عنصر الإنابة | `403` |
| محامٍ آخر (نفس الفرع) | `403` | `403` |
| محامٍ آخر (فرع آخر) | `403` | `403` |

- القائمة تُرشّح بملكية المستند/نطاقه لا بالفرع وحده: محامي نفس الفرع ممنوع.
- `pending` مخصّصة للرئيس (وشعبته) في هذا القياس؛ منع المدير/المشرف ملاحظة قائمة
  (قرار صلاحيات قائم، لا انحدار جديد) ومسجّلة للمراجعة مع `P2-01`.

## 2. ثغرة دلالة مكتشفة (موثّقة، تُصلح في تغيير مستقل)

محاولة محامٍ آخر حذف إنابة ليست له أعادت **`400`** لا `403`:

- `DocumentDelegationService.DeleteAsync` يستدعي `EnsurePendingByOwner`، وهي ترمي
  `ArgumentException` لكل من «ليست قيد الاعتماد» و«ليست للمستخدم»؛ و
  `GlobalExceptionHandler` يعيّن `ArgumentException` إلى `400`.
- كذلك إنابة غير موجودة ترمي `ArgumentException` (‏`400`) بدل `KeyNotFoundException` (`404`).

**لماذا لم تُصلح الآن:** تعداد الاختبارات الحالية التي تتوقع `ArgumentException` في
مسارات الإنابة كبير (عشرات الحالات في `DocumentDelegationServiceTests`/`SubHeadDelegationTests`)
؛ تحويل نوع الاستثناء داخل PR اختباري يخلط تغييرًا سلوكيًا واسعًا مع مصفوفة. الإصلاح
المقترح (مستقل، مع تحديث التوقعات صراحةً):

1. `EnsurePendingByOwner`: فحص الملكية أولًا بـ`UnauthorizedAccessException`، ثم فحص
   الحالة (`ArgumentException` يبقى لحالة «معتمدة/مرفوضة»).
2. `DeleteAsync`/`UpdateAsync`: إنابة غير موجودة ⇒ `KeyNotFoundException` (`404`).
3. تحديث اختبارات الخدمة المتوقعة + مصفوفة `P2-02d` لتؤكد `403`/`404`.

## 3. التحقق

  عبر API ثم يختبر 6 فاعلين × مسارين.
- المجموعة الكاملة `Api` تُعاد قبل الدمج.
- لا تغيير في الكود ولا الهجرات.

## 4. حدود

- المصفوفة تغطي **القراءة** (قائمة المستند + pending)؛ الكتابة (تعديل/حذف/assign/reject)
  مغطاة سلوكيًا في اختباراتها القائمة، ودلالة أخطائها بند الإصلاح أعلاه.
- لا تغطي الإنابة الخارجية/فروع أخرى بعمق، ولا `PostgreSQL` (`P1-01`).
