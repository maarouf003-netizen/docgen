# خطة إصلاحات توحيد تسميات الجهات العامة (`F1`–`F7` + `F12`)

> الحالة: **معتمدة، بانتظار التنفيذ** — لا يُنفَّذ أي بند قبل موافقة صريحة.
> القرارات المثبتة: النطاق **(ب)** (`F1`–`F6`)، الهدف الافتراضي **(ب)** (الأعلى ارتباطًا)، المندوبون **(ب)** (المطابق للفرع).
> خارج النطاق (مؤجل قصدًا): `F8`–`F11` (تنظيف وتجميل لا يغيّر سلوكًا).
> لا تغيير في مخطط قاعدة البيانات في أي بند → **لا هجرات EF → لا تنبيه نشر** (`RUN_GUIDE.md §9` غير مطلوب).

## نتيجة مراجعة الخطة (برمجيًا ومنطقيًا وبنيويًا)

- `F1`: سليم — لا اختبار يعتمد `ClusterId` (فُحص عبر `grep` في `backend/tests`: صفر نتائج)؛ الإصلاح سطران.
- `F2`: سليم — `ParseIdList` يقسّم بفاصلة (`EntityRegistryController.cs:271`) فيصح `join(',')`؛ أُضيف قيد: اشتقاق مفتاح نصي للاعتماديات منعًا لإعادة تشغيل المؤثرات.
- `F3`: سليم — يُنسَّق مع مؤثر تهيئة `F2` (التهيئة تستثني الهدف أصلًا).
- `F4`: سليم — `totalCount` متاح في العقد (`types/index.ts:1553-1559`)؛ أُضيفت اتفاقية التنسيق الرقمي للمشروع.
- `F5`: سليم — الخطاف موجود (`src/hooks/useDebouncedValue.ts:3`) ومستخدم في نفس الملف (`:191`).
- `F6`: سليم — حارس معرّف-طلب بنمط المشروع (علم `active`) دون `AbortController` جديد.
- `F7`: سليم — الترتيب الأبجدي مضمون خادميًا (`ArabicNameSimilarity.cs:213`) فالمقارنة الصارمة `>` تُبقي الأول عند التعادل حتميًا.
- `F12`: سليم — البذر متعدد-الفروع ممكن عبر `CreateAsync` المتكرر بنفس المعياري (`FindOrCreateGroupAsync` في `PublicEntityService.cs:519` يجمع القيود في مجموعة واحدة)؛ التوقيع الموسَّع خاص وداخلي فلا كسر عقود؛ حمولة التدقيق `branchMap` لا تُمس.

## ضوابط الأصول الصارمة (إلزامية لكل بند)

1. اختبارات مع كل تغيير سلوكي (أعلاه) + الحالات الحدّية: هدف غير موجود/غير نشط، `includeIds` فارغ/غير رقمي، ممتصة غائبة من الصفحة، تعارض `gov|branch`، اتحاد العدّاد، تواريخ (فارغ ← `null`، `١٥/٣/٢٠٢٦`، `not-a-date ← 400`).
2. تدقيق العقود عبر المسار: `EntityGroupListQuery/IncludeIds` → `ListGroupsAsync` → `PagedResult/TotalPages` → `types/index.ts`؛ `UnifyPreview/UnifyNamesResponse` حقلًا بحقل (بما فيها `decreeDate?: string?`).
3. فحص البقايا عبر `rg`: `ClusterId: 0` الثابت، `perPage: 500`، `filtered` المحذوف، `groups[0]` كهدف.
4. التحقق الكامل بعد التنفيذ: `dotnet test`، `dotnet build` (صفر تحذيرات)، `npx oxlint src`، `npx tsc -b`، `npx vitest run`، `npm run build`، وفحص جوال بصري لتبويب التوحيد (375px).
5. الترتيب المقترح: `F1` → `F12` (خلفي + اختباراته) → `F2`/`F3` → `F7` → `F4` → `F5`/`F6` → التحقق الكامل.
