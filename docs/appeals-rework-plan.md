### 2-3) `needsRotation` (R3) — الاشتقاق الدقيق

الحالي (`DocumentAppealService.cs:1002-1012`):

```csharp
var latestRecorded = a.BaseNumbers.Count > 0
    ? a.BaseNumbers.Max(b => b.Year)
    : int.TryParse(a.AppealYear, out var recordedYear) ? recordedYear : 0;
var hasCurrentYearRow = a.BaseNumbers.Any(b => b.Year == currentYear);
var needsRotation = a.Status == AppealStatusCatalog.Pending
    && latestRecorded > 0          // ← يُحذف (ليُسمح بلا أي رقم)
    && latestRecorded < currentYear
    && !hasCurrentYearRow;
```

بعد حذف الشرط: بلا أي رقم → `0 < currentYear` → `true` (زر يظهر — المطلوب)؛ والأصل
(`AppealYear`) بسنة اليوم بلا صف تدوير → `latestRecorded == currentYear` → `false` (يوجد رقم
فعلي — لا تمييز أحمر، صحيح)؛ والمنظور المدوَّر لسنة اليوم → `hasCurrentYearRow` → `false`.
`Pending` مدمج أصلًا فيغطي «ممنوع بعد الحسم/الشطب».
`needsRotation` تبقى **للتمييز الأحمر والتحذير فقط**، لا بوابةً للزر (الخيار ب — §4-4 و§7).

## 6) الحالات الحدّية (إلزامي)

1. فارغ/أبيض → `undefined`/`null` (آليات `clean/cleanDate` و`Bounded/ParseDateTime` قائمة — بلا تغيير).
2. استئناف بلا إسناد (`AssignedLawyerId = null`): يختفي من قائمة منشئه (مقبول صراحة)؛ يبقى لرئيس
   الفرع والإدارة + `ListForDocumentAsync` للمالك (وقوعات الملف) + تفاصيل مباشرة للمنشئ.
3. استئناف بلا أي رقم أساس: زر التدوير **يظهر** للمسند (أحمر — R3)؛ والإدخال الأول كان وما زال ممكنًا
   أيضًا عبر `تعديل القيد` (لا يُحذف).
4. أصل (`AppealYear`) بسنة اليوم بلا صف تدوير: `needsRotation = false` → زر محايد + ملاحظة كهرمانية
   (يوجد رقم فعلي)؛ إعادة التدوير مسموحة وتُلحق سجلًا أحدث يفوز.
5. مدوَّر لسنة اليوم برقم خطأ: التصحيح متاح عبر إعادة التدوير (سجل أحدث يفوز — سلوك مثبت باختبار
   `Rotation_OldYearNeedsRotation` سطور 446-462)؛ والحماية تأكيد مسبق يعرض القيمة والسجل (الخيار ب).
6. محسوم/مشطوب: لا تدوير (واجهة + خلفية) ولا نقل (مفرد مرفوض أصلًا؛ جملة يتخطى)؛ يبقى ظاهرًا عبر
   فلتر `محسوم/مشطوب` وفي وقوعات الملف؛ تذكيراته في اللوحة تبقى كما هي (قرار صريح — خارج النطاق).
7. رئيس بلا فرع: `BadRequest` القائم (بلا تغيير). مدير/إدارة: الكل + الافتراضي `منظور` (مقبول).
8. أرقام عربية في `appealYear`: التطبيع `normalizeArabicDigits` القائم (بلا تغيير).

  المدمجتين؛ صف إجراءات `colSpan` أفقي يساوي عدد الأعمدة المعروضة (مع/دون `المحامي المختص`)؛ أول

  ومحايد otherwise) ومخفي (للمنشئ غير المسند / للمحسوم)؛ زر نقل مخفي لغير المنظور.
- `AppealRotationModal` (جديد/موسّع): خطوة التأكيد تعرض القيمة والسنة والسجل؛ التنبيه الكهرماني عند
  وجود رقم لسنة اليوم.
- حالة فراغ: عنصر بلا أرقام يعرض `—` بلا كسر تخطيط (جوال 375 + مكتبي).

### خلفية (`dotnet test`)

- `DocumentAppealServiceTests.cs`: تدوير المنشئ غير المسند مرفوض؛ تدوير المحسوم/المشطوب مرفوض؛
  تدوير بلا أي رقم مسموح للمسند المنظور؛ إعادة التدوير لسنة اليوم تُلحق سجلًا أحدث يفوز (القائم —
