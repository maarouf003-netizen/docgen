## 3. اللقطات (`docs/audit/`)

- **الاصطلاح:** `NN-<slug>-YYYYMMDD.md` برقم متسلسل، ووثيقة/ملحق مؤرخ لكل تحديث.
- **سياسة:** اللقطة **لا تُحرَّر بعد التجميد**؛ أي تحديث بوثيقة/ملحق جديد (انظر `AGENTS.md`).
- **أين الحالة الحية؟** في الخريطة، لا في اللقطات. اللقطات دليل «ما قيس فعلًا ومتى».
- أحدث اللقطات: `49` (عقد الخطأ)، `50` (`D11`)، `51` (أمن الإنتاج)، `52` (المجمّع)، `53` (حدود المعدل)، `54` (عقد OpenAPI)، `55` (الحوكمة)، `56` (بوابة `npm audit`)، `57` (SAST)، `58` (حماية `CodeQL`)، `59` (`PII`)، `60` (الإصدار والاعتماديات)، `61` (أنواع `P6-06` المولَّدة)، `62` (فرز `CodeQL`)، `63` (حارس `CSP`)، `64` (منصة `PostgreSQL` للاختبارات)، `65` (نقل مجموعتَي الإدارة)، `66` (نقل المستندات + عيب 500)، `67` (نقل مجموعات الإنابة)، `68` (نقل الاستئناف/المتدخلين/التصدير)، `69` (نقل الدوائر والمراسلات)، `70` (نقل المستخدمين والجلسات)، `71` (نقل التنبيهات)، `72` (نقل الجهات والبوابة)، `73` (نقل الإحصاءات والتدقيق)، `73a` (ملحق تصحيح `72`/`73`)، `74` (نقل عائلة `RF` + حارس مولَّد)، `75` (بنية اختبار مشتركة + أول دفعة `P1-08`)، `76` (حارسا المخطط + قياس البحث)، `77` (التزامن المتفائل والنقل)، `78` (بقية مجموعات التزامن + علّتا الإنتاج)، `79` (إزالة `TestDb` المركزي).

## 4. الخطط

- الخطط الموضوعية في `docs/*_PLAN.md` (مثل تفكيك الخدمات، البوابة، التنبيهات) **مرجع تاريخي/تفصيلي**.
- **الحالة الرسمية** وقرارات النطاق في [`PERFECTION_ROADMAP.md`](PERFECTION_ROADMAP.md) فقط.
- عند تعارض خطة قديمة مع الخريطة: الخريطة هي الحاكمة، والخطة تُؤرشف.

## 6. عقد `API`

- [`openapi/docgen-v1.json`](openapi/docgen-v1.json) — لقطة `OpenAPI` المُطبَّعة (239 عملية).
- التحقق/التحديث: `OpenAPI` محروس باختبار `OpenApiContractTests`؛ التحديث الواعي فقط:
  `UPDATE_OPENAPI_SNAPSHOT=1 dotnet test --filter OpenApiContractTests`.
- **أنواع مولَّدة (`P6-06`):** `frontend/src/api/generated.ts` من اللقطة عبر
  `npm run generate:api` (`openapi-typescript`)، وحارس `CI` يفشل عند انحراف التوليد.
  أول نوع مُحال: `DashboardStatsDto`؛ إحلال بقية الأنواع تدريجي. `required` مشتق من
  nullability C# (`RequiredByNullabilitySchemaFilter`).

## 7. كيف تحدّث هذه الوثائق

- غيّرت سلوكًا؟ حدّث **الخريطة** (الحالة) + أضف لقطة `audit` بالأرقام.
- أضفت هجرة؟ سجّلها في `RUN_GUIDE.md` §9 **و**`AGENTS.md` في نفس التغيير.
- قرار معماري جديد؟ أضف `ADR` مرقّمًا في `adr/` واربطه من هنا.
- لا تكرّر النصوص الملزمة من `AGENTS.md` هنا؛ أشِر إليها.
