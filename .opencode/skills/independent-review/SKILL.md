# مراجعة مستقلة + طفرة فعلية قبل الدمج

إجراء إلزامي مكمّل لـ`AGENTS.md`. الغرض: منع «الثقة الزائفة» في اختبارات ووثائق يكتبها
المنفّذ نفسه.

## متى تُستخدم

- كل تغيير سلوكي (واجهة/خلفية/عقد/هجرة) قبل الدمج.
- كل لقطة `docs/audit` تدّعي «جُرّب فعلًا» أو «مثبت».
- كل مراجعة بأثر رجعي لمرحلة سابقة (انظر `docs/REVIEW_DEBT.md`).

## القاعدة الحاكمة

**الكاتب لا يكون المراجع.** المراجعة الذاتية مسموحة كتحضير، لكن لا تُسمّى «مراجعة
مستقلة» ولا تُغلق بها مرحلة. المراجع المستقل = جلسة/وكيل منفصل، أو شخص آخر، يقرأ
الفرع/الالتزام ولا يعدّل الملفات.

## الخطوات

1. **حدّد نطاق المراجعة بدقة:** `base..head`، الملفات، الادعاءات في الوثائق، والأسئلة
   الحرجة (خطأ/تحميل/فراغ/إلغاء/صلاحيات/تزامن/تخزين).

2. **سلّم المراجع حزمة:** فرق `git diff base..head`، اللقطات، الاختبارات، وأي ادعاء
   عددي (عدد أسطر/اختبارات/طلبات). لا تسلّمه خاتمة جاهزة.

3. **يجب على المراجع أن يثبت أو ينفي كل ادعاء:**
   - `مثبت`: أمر/اختبار/تشغيل فعلي (يذكر الأمر والنتيجة).
   - `تحليل ثابت`: قراءة كود فقط.
   - `غير مثبت`: ادعاء بلا دليل ⇒ يُعاد للكاتب.
   ولا يُقبل «مرّت الاختبارات» دليلًا على سلوك غير مختبَر.

4. **طفرة لكل اختبار جديد/حاسم:** عطّل السلوك المقصود (حذف مفتاح، إزالة حالة، قلب شرط)
   ثم شغّل الاختبار المتأثر، ثم **أعد التغيير فورًا**. سجّل:

   | الطفرة | الاختبار | قبل | بعد |
   |---|---|---|---|
   | ... | ... | فشل/مرّ | فشل/مرّ |

   إن مرّت الطفرة: الاختبار أجوف ⇒ أضف/قوِّ الاختبار قبل الإغلاق.

5. **امسح المسارات غير السعيدة:** خطأ أولي، خطأ بعد نجاح، إعادة محاولة، إلغاء طلب،
   تبديل هوية/نطاق، بيانات مخزَّنة قديمة، صفحة أخيرة، قيم فارغة/`null`.

6. **الحكم:** `BLOCK` / `APPROVE WITH FOLLOW-UP` / `APPROVE`. لا يُدمج مع `BLOCK`.
   `FOLLOW-UP` يتطلب بندًا في السجل أو ملحقًا مؤرخًا.

7. **التصحيح:** لا تُحرَّر لقطة `docs/audit` مجمّدة. التصحيح **ملحق مؤرخ** جديد
   يذكر الادعاء الخاطئ والدليل والإصلاح. وأيضًا حدّث `docs/REVIEW_DEBT.md` إن كان
   النطاق بأثر رجعي.

## قائمة تحقق المراجع

- [ ] الفرق مطابق للمزعوم (لا تغييرات مخفية/ملفات غير مقصودة).
- [ ] كل ادعاء موسوم: مثبت/تحليل ثابت/غير مثبت.
- [ ] الطفرات نُفِّذت وأُعيدت (لا طفرة متروكة في الشجرة).
- [ ] مسار الخطأ لا يعرض «فراغ/صفر» كاذبًا.
- [ ] الإلغاء/التخزين/الحداثة مفهومة ومختبَرة أو معلنة.
- [ ] الصلاحيات ونطاق البيانات لم تتغير بلا دليل.
- [ ] لا أسرار، لا `type="date"`، لا كسر عقد.
- [ ] البوابات أُعيد تشغيلها بعد التصحيحات.

## دين المراجعة القديم

- لا تنتظر انتهاء الخطة كلها. راجع بأثر رجعي **بموجات مخاطرة** حسب
  `docs/REVIEW_DEBT.md` (بيانات/أموال/صلاحيات أولًا).
- كل موجة: نطاق محدد + مراجع مستقل + طفرات + ملحق + سجل. لا «مراجعة شاملة» مفتوحة
  بلا حدود.
- الدين المغلق يُشطب بسطر يذكر PR/التاريخ/الملحق؛ الدين المتبقي يبقى ظاهرًا في
  الخريطة.

## ممنوعات

- وسم مراجعة ذاتية بأنها «مستقلة».
- كتابة «جُرّب» بلا أمر/نتيجة.
- تبييض `axe`/حراس بلا سبب وتاريخ انتهاء.
- تعديل لقطة مجمّدة بدل ملحق.
